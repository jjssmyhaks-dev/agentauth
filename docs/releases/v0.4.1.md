# v0.4.1 — Bug Audit & Hardening

_Published: 2026-09-21_

A full audit of the codebase surfaced **11 bugs across crash, logic, UI, and SDK layers** — all fixed in this patch, with a test suite added so they can't regress.

## Highlights

- **No more boot crashes from corrupted sessions.** A malformed `aa_user` value in localStorage used to crash the entire app on load. It's now handled defensively and self-heals by clearing the bad value.
- **Approvals actually filter.** The Pending/Approved/Denied tabs previously filtered against a value that never matched a status, so tabs could render empty. Tab → status mapping is now exact and guarded.
- **No more `NaN%` in Analytics.** The success-rate stat divided by zero when agents had no recorded actions; the token-usage chart also computed its scale before data existed.
- **The Rotate Key button works.** It had no click handler at all — dead button, fixed.
- **Python SDK token refresh unbroken.** `get_token()` crashed on every refresh because the timestamp parser rejected the `Z` suffix in ISO-8601 expiry strings.
- **TypeScript SDK errors are informative.** The fetch wrapper discarded API error bodies; structured reason codes now survive to the caller.

## Realtime architecture refactor

The `useRealtime` hook's ~250-line interval callback (a dozen refs, inline templates, simulation mixed with dispatch) is now a **pure event-sourcing engine** (`src/lib/simulation/engine.ts`) with an injectable RNG. Each tick returns a typed event list; the hook is a thin pump that dispatches to context actions. The engine is deterministic under a seeded RNG and fully unit-testable.

The extraction surfaced one more latent bug, also fixed: **session expiry was unreachable** — the idle-check branch in an `else` chain blocked the expiry branch, so sessions never expired.

## Testing & CI

- **27 regression tests** added (vitest + testing-library) pinning every fix above, plus engine coverage: determinism, unique IDs, health thresholds, session expiry, approval emission.
- **CI rewritten**: the workflow previously used Bun and only typechecked. It now uses npm (matching the lockfile) and runs **typecheck + tests + build** on every push and PR to `main`.
